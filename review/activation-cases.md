# Codex activation-case plan

No live result is recorded in Stage 1. Stage 3 will implement the thresholds in `docs/evaluation.md` using the six official skills, `review/starter-prompts.md`, direct/indirect/project-context requests, near-neighbor prompts, and non-Botpress negative controls.

Each case must record prompt, expected skill/reference behavior, observed behavior, package/upstream revision, Codex surface/version, model, OS, date, and repetition. Fresh conversations are mandatory for discovery checks. Skills-only review evidence must not invent MCP tools or MCP demo requirements.
